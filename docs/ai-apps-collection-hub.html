Put this live on GitHub — free

No server, no hosting bill. GitHub Pages serves static HTML directly from your repo — and these demos run entirely in the visitor’s browser, so they work on Pages as-is.

1
Add this file to the repo

Save this page as index.html in AI-Apps-Collection — either in the root or in a /docs folder. Commit and push to main.

2
Turn on Pages

In the repo: Settings → Pages → Build and deployment → Deploy from a branch. Pick main and the folder you used. Save.

3
Share the link

After ~1 minute GitHub shows your live URL at the top of the Pages settings. That’s the link to put on your portfolio, Upwork and Freelancer profiles.

Adding the next sub-app takes 2 minutes

Create the project folder in the repo as you already do for your daily work, add its README, then add one entry — with its demo — to the projects list in this hub file. The hub, search and filters pick it up.
